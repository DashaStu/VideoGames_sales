# Анализ рынка видеоигр (EDA)

Этот проект посвящен исследовательскому анализу данных (EDA) продаж видеоигр. 
Цель работы — выявить ключевые тренды индустрии, определить наиболее успешные жанры и проанализировать динамику рынка на основе открытых данных.

## 🛠 Стек технологий
* **Python**
* **Pandas** — очистка, фильтрация и агрегация данных.
* **Seaborn & Matplotlib** — визуализация трендов и распределений.
* **Jupyter Notebook** — интерактивная среда для анализа.

##  Основные этапы работы
1. **Предобработка:** Оценка качества данных, обработка пропущенных значений в колонке `Year`, приведение типов для корректных расчетов.
2. **Анализ:**
   - Выявление лидеров рынка: топ-5 жанров и крупнейшие издатели.
   - Расчет динамики продаж в мировом масштабе.
3. **Визуализация:** Построение графиков для интерпретации рыночных трендов.

##  Основные выводы
* **Тренды:** Наблюдается «золотой век» индустрии в период с 1995 по 2009 год.
* **Предпочтения:** Жанр **Action** является безусловным лидером по объемам продаж, что говорит о стабильно высоком спросе на этот сегмент.
* **Качество данных:** Выявлена неполнота данных в датасете за период после 2015 года, что требует осторожности при прогнозировании современных трендов.
